# Mini Photo Vault 📸

A React Native mobile application that allows users to capture, compress, upload, and manage photos with EXIF metadata support.

## Features

- 📷 Camera capture using Vision Camera
- 🗜 Image compression (70–80%)
- ☁️ Cloud upload (Cloudinary)
- 🔥 Firebase Firestore integration
- 🖼 Gallery view with FlatList
- 📍 EXIF metadata (Kotlin Native Module)
- 🔄 Pull-to-refresh
- 🗑 Delete photos
- 📊 Original vs compressed file size

## Tech Stack

- React Native CLI
- Vision Camera
- Firebase Firestore
- Cloudinary
- Kotlin (Native Module)

## Setup

```bash
npm install
npx react-native run-android
```

## Note

- `.env` file is not included for security
- Firebase warning logs suppressed for cleaner demo
